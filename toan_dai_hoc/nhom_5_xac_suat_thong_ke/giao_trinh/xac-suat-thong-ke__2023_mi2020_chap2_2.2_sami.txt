Tính chất của hàm phân phối

Tính chất 1
(a) 0 ≤ FX (x) ≤ 1 với mọi x ∈ R.
(b) FX (x) là hàm không giảm, nghĩa là với mọi x1 , x2 ∈ R, x1 < x2 thì FX (x1 ) ≤ FX (x2 ).
Nếu X là biến ngẫu nhiên rời rạc thì FX (x) là hàm gián đoạn với số điểm gián đoạn là số các giá trị có
thể có của biến ngẫu nhiên và liên tục bên trái tại những điểm gián đoạn đó.
(c) P (a ≤ X < b) = FX (b) − FX (a).
Nếu X là biến ngẫu nhiên liên tục thì P (X = a) = 0 và
P (a ≤ X < b) = P (a ≤ X ≤ b) = P (a < X ≤ b) = P (a < X < b) = FX (b) − FX (a).
(d) limx→−∞ FX (x) = 0, limx→+∞ FX (x) = 1.
