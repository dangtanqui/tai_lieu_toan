## Nguồn gốc
- Ban đầu mô phỏng não sinh học; hiện nay gần như không còn liên quan
- Lịch sử: 1950s → suy thoái → 1980–90 (nhận dạng chữ viết tay) → suy thoái cuối 1990s → hồi sinh ~2005 (**deep learning**)

## Ứng dụng
- Speech recognition, computer vision (ImageNet 2012), NLP, quảng cáo, y tế, khí hậu, v.v.

## Nơ-ron sinh học vs nhân tạo
- Sinh học: dendrite (đầu vào) → cell body → axon (đầu ra)
- Nhân tạo: input số → tính toán → output số — mô hình toán đơn giản hơn nhiều
- Hầu như không hiểu não hoạt động thế nào → không nên lấy sinh học làm motivation quá nghiêm túc

## Tại sao bùng nổ gần đây?
- **Big data**: logistic/linear regression không scale tốt với dữ liệu lớn
- Mạng lớn hơn → hiệu năng tiếp tục tăng theo dữ liệu
- **GPU** hỗ trợ tính toán song song hiệu quả
