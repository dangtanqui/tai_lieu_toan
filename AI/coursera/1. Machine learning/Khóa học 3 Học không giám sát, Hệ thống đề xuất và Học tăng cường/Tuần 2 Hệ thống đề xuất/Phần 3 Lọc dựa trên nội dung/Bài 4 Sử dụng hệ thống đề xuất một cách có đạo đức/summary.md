## target đề xuất — không phải lúc nào cũng vì user

| target | Mô tả | Đánh giá |
|----------|-------|----------|
| Phim 5 sao | User sẽ thích | ✅ Hợp lý |
| Sản phẩm mua | User có thể mua | ✅ Hợp lý |
| Quảng cáo click + bid cao | Tối đa doanh thu | ⚠️ Có thể gây hại |
| Sản phẩm lợi nhuận cao | Không phải phù hợp nhất | ⚠️ Thiếu minh bạch |
| Tối đa thời gian xem | Giữ user trên site | ⚠️ Rủi ro nội dung độc hại |

## Ví dụ quảng cáo

- **Du lịch tốt**: phục vụ tốt → lợi nhuận cao → bid cao → nhiều traffic → vòng luẩn quyết tích cực
- **Payday loan khai thác**: khai thác khách → lợi nhuận cao → bid cao → **khuếch đại doanh nghiệp có hại**

## Vấn đề tối đa engagement

- Khuếch đại **thuyết âm mưu**, nội dung thù hận, độc hại — vì chúng giữ chân user
- Giảm thiểu: lọc hate speech, lừa đảo, bạo lực (định nghĩa khó)

## Nguyên tắc đạo đức

- **Minh bạch** với user: tiêu chí đề xuất là gì?
- Mời **nhiều quan điểm** thảo luận trước khi triển khai
- Chỉ xây dựng thứ thực sự làm xã hội **tốt hơn**
