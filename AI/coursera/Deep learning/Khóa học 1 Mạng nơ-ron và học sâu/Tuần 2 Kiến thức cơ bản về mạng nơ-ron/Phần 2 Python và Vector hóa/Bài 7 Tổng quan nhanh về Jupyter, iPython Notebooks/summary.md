## Jupyter / iPython Notebooks trên Coursera

- Môi trường làm **programming assignment** tuần 2

## Cấu trúc notebook

| Thành phần | Mô tả |
|---|---|
| Text/markdown | Hướng dẫn bài tập |
| Code cell (xám) | Khối code cần chạy/sửa |
| `# START CODE HERE` … `# END CODE HERE` | Vùng viết code của bạn |

## Thao tác cơ bản

- Chạy cell: **Shift + Enter** hoặc Menu → Cell → Run Cell
- Double-click markdown → hiện raw syntax → chạy cell để render lại
- Chạy **các cell trên** trước (import numpy, khởi tạo biến) dù không cần sửa code

## Xử lý sự cố

- Kernel chết / lỗi kết nối → **Kernel → Restart Kernel**
- Job quá lớn hoặc idle lâu có thể làm kernel crash

## Nộp bài

- Hoàn thành code → nút **Submit Assignment** (góc trên phải)
- Notebook hỗ trợ học nhanh: viết vài dòng → xem kết quả ngay
