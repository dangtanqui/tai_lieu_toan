## Thực tế của RL hôm nay

- RL **hấp dẫn** về mặt nghiên cứu nhưng có phần **bị thổi phồng** (hype)
- Vẫn là **một trong ba trụ cột** ML; tiềm năng tương lai lớn

## Hạn chế quan trọng

- Nhiều paper dùng **mô phỏng / video game** — chuyển sang **robot thật** khó hơn nhiều
- Ứng dụng thực tế RL **ít hơn** supervised và unsupervised learning
- Khi build sản phẩm: xác suất cần supervised/unsupervised **cao hơn** RL

## Khi nào dùng RL?

- Điều khiển robot, tối ưu tuần tự, trò chơi — khi khó gán nhãn action đúng
- Cần chỉ định **reward** thay vì demo từng bước
